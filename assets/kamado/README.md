# Фото грилів Kamado Bono

Покладіть сюди офіційні фото моделей (JPG або WebP, бажано на світлому чи прозорому тлі, ширина 800–1200 px)
і впишіть назву файлу в поле `photo` відповідної моделі в `kamado/index.html` (масив `MODELS`),
наприклад `photo: 'media.jpg'`. Поки поле порожнє, показується малюнок.
